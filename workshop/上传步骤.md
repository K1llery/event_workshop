# 隐藏上传 Event Workshop

此次目标为隐藏（Private），暂不公开。上传文件位于 D:\IsaacWorkshop；当前游戏 mods/event_workshop 和游戏存档没有改动。

1. 保持 Steam 客户端运行并登录拥有此游戏的账号，双击：
   D:\SteamLibrary\steamapps\common\The Binding of Isaac Rebirth\tools\ModUploader\ModUploader.exe
   窗口标题虽然写着 Afterbirth+，该官方工具也用于忏悔+。
2. 点击 Choose Mod...（或 Choose Metadata），选择：
   D:\IsaacWorkshop\event_workshop\metadata.xml
3. 点击封面旁的 Change，选择：
   D:\IsaacWorkshop\preview.jpg
4. 核对 Name 为 Event Workshop；说明应已自动载入；Visibility 必须为 Private。
   将 D:\IsaacWorkshop\change-notes.txt 的内容粘贴到 Change Notes。
5. 点击 Upload Mod，等待日志出现 Successfully uploaded...，随后点击 View Mod。
   如果页面要求接受 Steam Workshop 协议，请自行阅读并接受后再检查页面。
6. 保持隐藏，确认标题、中文封面、中英文说明正常；把 View Mod 打开的创意工坊链接发回本聊天。

上传成功后，官方工具会在上传目录的 metadata.xml 中写入 id，并更新 version。保留这个文件，后续更新使用同一条目。不要把上传目录的 metadata.xml 覆盖到当前游戏安装目录；该安装目录仍保留本机已经验证的开发安装信息。

官方上传工具的 version 是上传修订号，功能版本为 MCM 与日志中的 1.0.2。后续上传须让工具正常增加修订号，不能用固定的开发安装版本替换它。

如果报错，先保留工具中的错误文字和代码并发回聊天。不要删除已生成的条目 ID 或重新创建多个条目。

Codex Windows 自动化接口在本 WSL 项目中初始化失败，错误为：
codex/sandbox-state-meta: sandboxCwd is not a local file URI: file:///home/mr/projects/isaac_mods
因此本次上传按钮需要用户手动完成，不是额外的权限确认。
