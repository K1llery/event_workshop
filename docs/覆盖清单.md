## 受限和未接入内容

- 直接检测：原版可用回调通知、可读取状态的变化。通用 native_callback 可选择回调 ID；渲染／更新类通知只能观察，执行仍延迟到逻辑更新，且受限流保护。
- 推断检测：成功拾取、购买、箱子／机器交互、障碍破坏；这些不具有 REPENTOGON 的精确专用回调。敌人死亡归属不总是可确定。
- 参数覆盖：全部 31 个道具池、原版枚举的拾取物／敌人类型／效果／跟班／卡牌／药丸效果／饰品／音效／角色／标记。敌人变体及子类型提供数值输入，不声称所有组合有效。
- 持续效果来源：原版不能完整追踪某些道具效果、爆炸、状态伤害和世界操作；在当前房间保守继承因果链，可能减少重复触发。
- 不采用失效的 MC_LEVEL_GENERATOR；不采用可能发生 C++ 栈损坏的 StartStageTransition，换层改用固定原生 stage 命令。
- 不提供覆盖回调返回值的规则，不取消原版行为；不提供自动更换开局种子、重开局、修改外部文件或永久解锁。
- 地图可见性、临时效果、机器动画与房间状态遵循原版刷新和持久化机制；剧情首领和特殊房间不能任意放置。
- 临时效果与持有物不是等价操作；口袋主动的槽位、角色生命和专用资源也受原版限制。
